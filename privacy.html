Site Privacy

Last updated: March 2026

Summary

Sunbunny keeps tracking intentionally small. The plugins themselves do not phone home, and this website only loads Meta Pixel if you explicitly opt in.

What the plugins do

  • No plugin telemetry: The downloadable plugins do not send analytics, usage data, or crash reports back to Sunbunny.
  • No plugin network access: The plugins do not connect to Sunbunny servers in normal use.

What the website does

If you accept, Sunbunny loads Meta Pixel to measure whether advertising is sending people to the right pages and download buttons. In the first version, that means page views and download-button clicks only.

  • No Meta before consent: The site does not load Meta Pixel until you opt in.
  • Rejecting is fine: The site still works if you reject.
  • Privacy Settings: You can change your choice later using the Privacy Settings control in the footer.
  • Global Privacy Control: If your browser sends a GPC signal, Sunbunny treats that as a request to keep Meta Pixel off.

Local storage

This site stores your privacy choice in your browser so it can remember whether Meta Pixel should stay on or off on later page loads.

Third-party services

GitHub Pages hosts this website, and GitHub Releases hosts downloadable plugin files. If you opt into Meta Pixel, Meta may receive standard browser request data associated with those events according to Meta’s own policies.

Contact

Questions about privacy? Reach out through the Sunbunny GitHub discussions linked on each plugin page.
