Privacy Policy

Last updated: March 2026

Summary

Sunbunny Absolutely Smashing does not collect, transmit, or store any user data. Period.

Details

  • No telemetry: The plugin does not phone home, send analytics, or collect crash reports.
  • No network access: The plugin makes zero network connections at any time.
  • No personal data: The plugin does not read, write, or access any personal files beyond the standard VST3 plugin scan performed by your DAW.
  • Website tracking is consent-gated: This website is static HTML hosted on GitHub Pages. It only loads Meta Pixel after you explicitly opt in, and you can change that choice later through Privacy Settings.
  • Consent memory: The website stores your privacy choice in browser storage so it can remember whether Meta Pixel should stay on or off on later page loads.

Website tracking and third-party services

If you accept website tracking, Sunbunny uses Meta Pixel for ad measurement and download-button analytics only. In the first version, this means page views and download clicks. If your browser sends a Global Privacy Control signal, Sunbunny treats that as a request to keep Meta Pixel off.

The download buttons on this site fetch release information from a local releases manifest hosted alongside the site. GitHub Pages hosts the site itself and GitHub Releases hosts the downloadable files; GitHub may log standard request data according to their own privacy policy.
